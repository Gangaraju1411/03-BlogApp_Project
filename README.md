  # Blog Application

A web-based blogging application built using Java and Spring Boot that allows users to create, publish, and manage blog posts, interact through comments, and communicate through messages.

## Features

- Create and publish blog posts.
- View and manage published posts.
- Add comments to blog posts.
- Delete posts and manage their associated comments.
- Send and manage messages.

## Tech Stack

- **Language:** Java 8
- **Backend:** Spring Boot 2.7.12, Spring MVC
- **Persistence:** Spring Data JPA, Hibernate
- **Database:** MySQL
- **Frontend:** Thymeleaf, JSP, JSTL
- **Utilities:** Lombok
- **Build Tool:** Maven
